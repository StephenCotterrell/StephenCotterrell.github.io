# StephenCotterrell.github.io

Static personal portfolio for Stephen Cotterrell, deployed with GitHub Pages at stephencotterrell.com.

## Local preview

Open `index.html` directly in a browser, or serve the directory with any static file server.

## Notes

- The site is plain HTML and CSS, with no build step or JavaScript dependency.
- Contact, resume, social, and project links should only be added when verified URLs or files are available.
- `about.html` redirects old traffic to the About section on the homepage.

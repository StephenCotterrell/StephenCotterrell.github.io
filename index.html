Local prototype

walkable.work

Go · PostgreSQL/PostGIS
React · MapLibre

A map for exploring Bay Area employer offices near a chosen location.

The Go API supports spatial searches, validated data imports and a report-review workflow. The React map handles changing searches, saved places and failed requests.

It maps employer offices rather than open jobs. Walking reach is a distance estimate, without street routing.

Twig

Go · Linux · Bubble Tea

View Twig on GitHub ↗

A terminal interface for managing WireGuard tunnels on Linux.

I built it to switch between local profiles and see which tunnels are active without typing out configuration names. It separates the terminal UI from command execution and tracks which operations succeeded or failed when working with multiple tunnels.
